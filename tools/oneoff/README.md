# 一次性脚本归档

这里的脚本**已经执行完毕**，保留的目的是留下「当时怎么改的」的可查记录，
而不是让你再跑一遍。它们匹配的是改动前的代码形态，现在执行只会报「未找到模式」。

| 脚本 | 当时做了什么 |
|---|---|
| `codemod-tokens.mjs` | 把组件里散落的 13 个硬编码 `fontSize`、10 个 `borderRadius`、`#fff` 等颜色字面量批量替换为设计 token。共改动 6 个文件 / 104 处。 |
| `codemod-polish.mjs` | 第二批语义性修复：残留色字面量归 token、快捷指令与审批按钮改用 CSS 类（让移动端 44px 生效）、设置里 14px 的 MCP 启停开关扩到 44px 可点区域。 |

两个脚本都做了两件值得沿用的事：

1. **匹配不到就抛错**，不静默跳过 —— 否则「改完了」可能只是模式没命中。
2. **保留原文件的行尾**（CRLF/LF）—— 这个仓库在 Windows 上开发，跨行尾的多行模式匹配
   会全部失配，而按统一行尾写回会让整个文件产生无意义的 diff。

仍然在用的是 `../make-icons.mjs`（生成 PNG 图标）和 `../png-read.mjs`（读回像素做断言）。
